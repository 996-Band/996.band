# 996 Band Content Manager

这是一个只在本机运行的内容管理工具，用于维护 PHOTOS、NOTICE、ARTICLES 和 ALBUMS。

乐队成员第一次使用时，请优先阅读更完整、更易懂的
[《内容后台使用手册》](../../docs/CONTENT-MANAGEMENT.md)。本文只保留工具本身的技术说明。

## 启动

```bash
pnpm photos:manage
```

也可以使用更通用的命令：

```bash
pnpm content:manage
```

启动后会自动打开：

```text
http://127.0.0.1:4310
```

管理服务只监听 `127.0.0.1`，不会作为网站页面发布到线上。

## 功能

- PHOTOS：选择照片文件夹，一键生成相册、大图、缩略图、视频封面和配置；支持修改信息、封面和顺序、删除相册。
- NOTICE：新增、启停、修改优先级、日期、链接和摘要。
- ARTICLES：新增和编辑 Markdown 文章、标签、摘要及草稿状态。
- ALBUMS：维护专辑或单曲、封面、类型、链接、优先级和首页启用状态。
- BUILD：在管理页面右上角执行完整网站构建检查。

视频处理依赖本机 `ffmpeg`。仅使用照片时不需要额外操作。

管理页顶部会显示当前媒体模式：

- `LOCAL ASSETS`：生成内容并保存在仓库中，网站读取本地资源。
- `OSS CDN`：生成完成后先上传 OSS、校验 CDN，再写入正式内容。

OSS/CDN 的首次配置和迁移步骤见 [`../media/README.md`](../media/README.md)。

## 本地预览

内容管理工具不会替代网站开发服务。需要预览网站时，在另一个终端运行：

```bash
pnpm dev
```

然后打开 `http://127.0.0.1:4321`。

## 安全边界

- 工具只修改当前仓库中的内容和素材。
- 工具不会自动提交 Git，也不会自动推送 GitHub。
- 删除操作会要求浏览器二次确认。
- 新增相册失败时不会写入正式配置。
- OSS 凭证只从本机 `.env` 读取，管理接口不会返回或显示凭证。
